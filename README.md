# courses

Short, visual lessons built with the `/teach` skill, as plain HTML pages. Published with GitHub Pages; open `index.html` locally for the same thing.

| Course | What it covers |
| --- | --- |
| [kotlin](kotlin/index.html) | Reading Kotlin as a TypeScript developer: null safety, scope functions and `when` |
| [kubernetes](kubernetes/index.html) | Kubernetes for Node developers: the components, one request traced from browser to pod, and what Kubernetes is and isn't good at |

Every page links the shared styles and quiz widget in [`assets/`](assets).
